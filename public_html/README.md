# public_html - the ASMA website

The deployable website for https://asma.atari.org. Uploaded via `bat\upload.bat`
(FTP), previewed locally via `index.bat` (Chrome with
`--allow-file-access-from-files`, so the site also works from `file://`).

## Structure

| Path | Content |
|---|---|
| `index.html` | Static info page: FAQ, native player list, links. |
| `style.css` | Styles for the info page. |
| `sitemap.xml` | Sitemap for search engines. |
| `index.bat` | Local preview helper: restarts Chrome with local file access and opens `index.html` and `asmadb/asmadb.html`. |
| `.htaccess` | 1-hour expiry, `Access-Control-Allow-Origin: *` (lets external players stream files directly), `noindex` for `.sap`/`.ttt` files. |
| `.well-known/` | Hosting/ACME infrastructure. |
| `asma/` | Junction to the SVN checkout (`bat\checkout.bat` creates it) - the actual music archive, served under `/asma/...`. Not in git. |
| `asmadb/` | The browser player application, see below. |
| `bin/` | Downloads: `SAPFileEditor.zip`, `archive/`, `obsolete/` (old players/tools). |
| `font/`, `img/` | Webfont and images (favicon, flags, statistics chart). |
| `rgb/` | The RGB browser game (HTML port). |

## asmadb - the player application

A self-contained, framework-free single-page application. No build step; plain
`<script>` tags with `?version=` cache busters. Four layers:

### 1. Data (generated by ASMAExporter, do not edit)

| File | Content |
|---|---|
| `asmadb.js` | The database as JavaScript: `const asma = {composerInfos, groupInfos, fileInfos, demozoo}`. Loaded as a script (not fetched) so the app works from `file://`. |
| `asmadb.json` | The same content as plain JSON for API consumers (e.g. the Java `ASMAClient` in `asma-lib`). |
| `asmadb.html` | Static HTML rendering of the database (`history/` keeps dated copies, not in git). |
| `asma.zip` | The complete archive download, packed by `bat\checkout.bat`. Not in git. |

### 2. Emulation (from the ASAP project, do not edit)

| File | Content |
|---|---|
| `asap-with-asapwriter.js` | The ASAP player/writer as ES module, generated from the upstream ASAP sources (JS sibling of the `asap.jar` used by `asma-tools`). |
| `asapweb.js` | ASAP's WebAudio glue (`ScriptProcessorNode` rendering). |

### 3. Domain model (hand-written)

| File | Content |
|---|---|
| `file.js` | `FileInfo`/`FileInfoList`: file model, URL file path scheme (`filePath#songNumber`), date format validation. |
| `composer.js` | `ComposerProxy`/`ComposerList`: maps authors and `Composers/` folders to verified composers, creates unverified proxies for unknown author strings, per-country statistics. |
| `demozoo.js` | Demozoo production maps (by ID, by URL file path), link-health summary, link HTML builders. |

### 4. Application and UI (hand-written)

| File | Content |
|---|---|
| `asma.js` | The main application (`ASMA` class, `window.asmaInstance`, ES module): search, player UI, hash routing `#/<filePath>/<song>`, shuffle and details mode, local file playback, format export, edit/submit dialog (re-tagged SAP download + `mailto:` to the ASMA team). |
| `ui.js` | DOM helpers (`UI`): element lookup, tabbed panes, modal dialogs, HTML encoding, sortable result tables. |
| `util.js` | `Logger` (optional on-page log via `?debug=1`) and `Util` (hex/duration/country-flag formatting). |
| `asma.css` | Styles for the application. |
| `index.html` | The application page: player, search form, dialogs. |
| `play-pause-button.svg`, `stop-button.svg` | Player icons. |

### Third-party and tools

| File | Content |
|---|---|
| `sorttable.js` | Sortable tables (Stuart Langridge). |
| `FileSaver.js` | Client-side file download. |
| `demozoo-music-new.js` | Not part of the page: a Tampermonkey userscript that prefills Demozoo's "new music" form from URL parameters. |
| `asma-statistics.ods` | Source spreadsheet for `img/asma-statistics.png`. |

## Mirrored logic (keep in sync)

Three pieces exist both here and in the Java `asma-lib`:

- Default values omitted from the export (`asma.js` init ↔ `ASMAClient.applyDefaults`).
- The `FileInfo` model (`file.js` ↔ `org.atari.asma.FileInfo`).
- The URL file path scheme `filePath#songNumber` (`file.js` ↔ Java `FileInfo.getURLFilePath`).
